# 키컸으면 UIUX 프로토타입

[프로토타입 열기](https://hansabari.github.io/kikeosseum-uiux-prototype/)

기능별로 화면을 전시하고, 원하는 화면에서 직접 눌러볼 수 있는 HTML 프로토타입입니다.

- [시연용 화면 전시](https://hansabari.github.io/kikeosseum-uiux-prototype/?view=gallery&section=all&mode=demo)
- [출시용 화면 전시](https://hansabari.github.io/kikeosseum-uiux-prototype/?view=gallery&section=all&mode=release)
- [온보딩부터 직접 체험](https://hansabari.github.io/kikeosseum-uiux-prototype/?view=play&section=onboarding&mode=demo)

가입·온보딩, 홈, 성장의 운동·식사·수면, 리포트, 내 정보를 포함합니다. 시연용 80개·출시용 88개 화면 상태와 이전 시안 5개를 볼 수 있습니다.

기록·계정·인식·예측·분석 응답은 합성 데이터입니다. 실제 인증·문자·AI·백엔드 API에 연결하지 않습니다. 촬영 화면은 브라우저의 카메라 권한을 사용할 수 있습니다.

HTML·CSS·JavaScript 정적 파일이며 GitHub Pages에서 제공합니다.
